# Visual Verification Rule

Before asking the user to check or test any UI, 3D scene, or visual changes:
1. Always open the application locally using the `browser_subagent`.
2. Navigate to the relevant screen / start gameplay.
3. Capture a visual screenshot and inspect the rendering yourself.
4. Verify all 3D models, textures, animations, positions, and UI elements are rendering accurately before handing off to the user.
